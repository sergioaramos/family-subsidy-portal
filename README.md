# Family Subsidy Portal

Portal para que los afiliados de una **caja de compensación familiar** radiquen en línea solicitudes de subsidio en especie (**kit escolar** y **computador**) para sus hijos, y para que el área de Subsidios las revise y decida, con control estricto de cupos.

**Stack:** AWS Amplify Gen 2 (TypeScript) + React, 100% serverless.

**Demo:** https://main.d2adbber7thoa2.amplifyapp.com — registro validado contra un core simulado (documento de prueba `10010001`), radicación con soporte, revisión por un analista con MFA.
